## 已完成（v5）

- [x] **实时动态选基**：盘前读取 16 只赛道盘中估值 + 动量，综合分排序取 Top4（非写死）。
- [x] **PROFIT_FIRST 框架**：赚钱优先 + 风控纪律 + 持仓生命周期管理。
- [x] **ML 研究模块**：LSTM / Attention / RF / 集成；回测中改为**静态排名**（每只基金仅训练一次，避免逐点重训过慢/不稳），诚实降级为研究（样本外跑输等权）。
- [x] **交易成本建模** `cost_model.js`：C 类赎回费阶梯 + 销售服务费，回测计入真实摩擦。实跑发现：每 5 日再平衡累计产生 **4%~6% 成本拖累**，直接验证"成本不可忽略"这一量化共识。
- [x] **现代组合理论** `portfolio_optimizer.js`：马克维茨最大夏普（Monte Carlo 有效前沿）+ 风险平价（等风险贡献）。
- [x] **walk-forward 防前视偏差**：MPT / 风险平价权重仅用前 60 日窗口拟合。
- [x] **多策略回测 + HTML 报告** `backtest_model_compare.js`：`reports/backtest_YYYYMMDD.html`（含成本/含 MPT/风险平价的 5 策略对比 + 权益曲线/回撤/有效前沿 SVG）。实跑区间 2026-03-25~07-21，马克维茨最大夏普组合三维最优。
- [x] **回测可视化** `report_chart.js`：零依赖 SVG 权益曲线 / 回撤 / 有效前沿。
- [x] **LLM 自然语言解读** `llm_report.js`：OpenAI 兼容接口，环境变量注入密钥，未配置优雅跳过；**已接入每日钉钉推送**（配置 `LLM_API_KEY` 时自动追加 AI 解读段）。
- [x] **工程化**：MIT LICENSE、CI 自动测试、架构/策略流程图、示例持仓脱敏。

## 规划中（v6+，按优先级）

### P0（严谨性，量化金融基本功）
- [ ] 因子库：动量 / 估值 / 质量 / 情绪多因子，替代单一动量信号。
- [ ] 更严格的 walk-forward：扩展窗口 + 多起点交叉验证，给出策略稳定性区间。
- [ ] 参数敏感性分析：maxWeight / REBAL 的稳健性热力图。

### P1（理论深度）
- [ ] 阈值再平衡（VanAurum 思路）：偏离目标 ±X% 才调仓，减少无效交易。
- [ ] 多周期协方差估计（EWMA 波动率）替代等权样本协方差。
- [ ] 风险预算推广：设定不同赛道风险预算（而非等权重风险贡献）。

### P2（AI × 金融 交叉，契合智慧治理学院方向）
- [ ] LLM 多 Agent 辩论：买入前多/空 Agent 辩论，降低单一信号误判。
- [ ] 新闻/舆情因子：接入财经新闻做情绪因子（参考 FinRobot）。
- [ ] 可解释性报告：每个买卖决策给出"因子贡献归因"。

## 与考研方向的契合点

目标：**中国人民大学苏州校区 · 智慧治理学院 · 电子信息（AI 与智慧治理方向）**。
该方向导师偏好**金融 / 量化**交叉，因此本项目刻意强化：
- **金融工程严谨性**：MPT、风险平价、交易成本、walk-forward —— 直接对应量化金融课程内核；
- **AI 应用能力**：ML 信号、LLM 解读、Agent 化规划 —— 对应 AI 方向；
- **工程规范**：CI、测试、开源协议、可视化 —— 对应"智慧治理"所需的系统落地能力。

> 一句话定位：**用 AI 与量化方法，解决个人基金投资的资产配置与择时问题**——
> 既是机器学习应用，也是金融工程实践，呼应"AI × 金融"交叉人才培养目标。
