# 量化方法升级说明（复试作品素材）

> 本文档面向**研究生复试 / 作品展示**，把 `stock-fund-advisor` V6 的量化升级点，用「做了什么 → 对应哪门量化金融知识 → 导师可能追问什么」的结构讲清楚。
> 目标院校方向参考：中国人民大学苏州校区 · 智慧治理学院（偏好金融 / 量化交叉）。

---

## 一、P0：因子工程 · 严格验证 · 稳健性

### 1. 多因子库（动量 / 估值 / 情绪）
- **做了什么**：`src/factor_library.js` 把选基从「拍脑袋 / 单一动量」升级为三大类多因子：
  - 动量：1/3/6 月收益、MA 斜率、短期反转；
  - 估值：净值历史分位、相对 MA60 折价、MA20 回撤（基金无 PE/PB，用历史分位代理「便宜度」）；
  - 情绪：市场恐慌贪婪指数 + 新闻舆情 + 个股波动放大。
  - 跨标的 **z-score 标准化**后加权合成 alpha 分，驱动「因子模型」策略。
- **对应知识**：Fama-French 多因子模型、截面标准化、alpha 因子合成。
- **导师追问**：为什么 z-score？→ 不同因子量纲不同（收益% vs 分位 0~1），z-score 让它们在同一尺度可比；估值因子为何取负向？→ 使「越便宜 = 分越高」，语义统一为"越大越好"。

### 2. 更严格的 Walk-Forward
- **做了什么**：`src/walk_forward_pro.js` 把历史切成多折，每折用**之前**的训练窗拟合权重、在**之后**的测试窗**真样本外**持有（测试窗内不重拟合），并输出**过拟合退化度 Δ = 训练窗夏普 − 样本外夏普**。
- **对应知识**：时间序列交叉验证、前视偏差（look-ahead bias）、López de Prado《Advances in Financial Machine Learning》的 walk-forward / Purged K-fold。
- **导师追问**：和简单的 train/test split 区别？→ 单次切分随机性大、只验证一次；walk-forward 多折滚动，更贴近实盘「用过去预测未来」且能统计过拟合。

### 3. 参数敏感性热力图
- **做了什么**：`src/sensitivity_heatmap.js` + `report_chart.heatmapSVG` 在「动量权重 × 估值权重」网格上回测，渲染收益热力图。
- **对应知识**：参数鲁棒性检验、过拟合诊断（收益只在极小区域最优 = 鲁棒性差）。
- **导师追问**：热力图能说明什么？→ 若高收益只集中在某个参数点，说明策略对该参数敏感、泛化差；大范围绿色才稳健。

## 二、P1：成本意识 · 波动率建模

### 4. 阈值再平衡（Threshold / Tolerance-band Rebalancing）
- **做了什么**：`walk_forward_pro.thresholdBacktest` 仅在当前权重偏离目标超过 ±X% 才调仓。
- **结论（实测）**：对**稳定目标（等权）**，调仓从「每 5 日一次」降到几乎不调，**同等收益、摩擦成本趋零**；对信号频繁更替的因子模型收益有限——这正暴露了「高换手 = 高成本拖累」的真问题。
- **对应知识**：再平衡成本、无交易区间（no-trade band）、Vanguard / 晨星再平衡研究。
- **导师追问**：为什么阈值再平衡有时也没用？→ 当目标本身频繁变（因子信号每周换），阈值只是"何时追上新目标"，省不掉信号驱动的换手。

### 5. EWMA 协方差 / 风险平价
- **做了什么**：`portfolio_optimizer.ewmaCovariance / riskParityEWMA` 用指数加权（RiskMetrics λ=0.94）给近期波动更高权重。
- **对应知识**：波动率聚集（volatility clustering）、RiskMetrics 风险模型、EWMA 协方差估计。
- **导师追问**：EWMA 比等权样本协方差好在哪？→ 金融市场波动聚类，近期信息预测未来更准；λ 越小越重视近期，需权衡噪声。

## 三、P2：可解释 AI · 多 Agent 辩论

### 6. 新闻舆情因子
- **做了什么**：`src/news_sentiment.js` 复用词典型舆情打分，把财经新闻映射为数值因子（∈[-1,1]）接入情绪类因子；网络失败安全降级。
- **对应知识**：文本情感分析、另类数据（alternative data）在量化中的使用。

### 7. LLM 多 Agent 多空辩论
- **做了什么**：`llm_report.multiAgentDebate` 看多 / 中性 / 看空三个 Agent 并行论证，再由裁判综合。
- **对应知识**：FinAgent / 多 Agent 金融决策、"对抗性论证 → 合成"范式；**确定性计算与 LLM 叙述分离**（计算由代码保证可审计，叙述由 LLM 生成）。
- **导师追问**：为什么要多 Agent 而不是一个？→ 单一 LLM 容易顺着用户预期说，多 Agent 对抗能逼出风险与反方观点。

### 8. 决策可解释归因
- **做了什么**：`src/decision_explain.js` 把每笔买卖归因于具体因子贡献（动量 / 估值 / 情绪各多少），生成人话说明。
- **对应知识**：可解释 AI（XAI）、因子归因、模型可信度。

## 四、一句话总结（复试自我介绍可用）

> 我把一个"帮我管基金"的小工具，做成了具备**多因子选基 + 严格 walk-forward 防过拟合 + 成本建模 + 参数敏感性诊断 + 可解释 AI 归因**的决策框架；所有计算可审计、网络失败安全降级，并产出可直接在浏览器查看的回测报告——体现了"AI × 量化金融"交叉的工程与研究能力。
